> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Tech Stack:** Electron 主进程（CommonJS/TS strict）+ React renderer + vitest（electron 集中 / renderer 贴源）。

**Spec:** `momo-hub/docs/specs/2026-10-27-momo-hub-m2.2-distribution-closure-polish.md`（本计划从 spec 出发，执行者两份都读）

## Review Focus（spec 隐含但易漏的输入类）

1. **发布已装 hub 旧版资源再发布新版权**：回填必须单行更新不叠行（升版语义）——T1 测试锁
2. **回填时目标行被并发删除**（卸载竞态）：DELETE+INSERT 原子窗内零残留——T1 用例（卸载后立即重发）
3. **readonly 会话的非写工具调用不受影响**：读类工具（read/grep）照常执行——T3 专项（防过度拒）
4. **同 slug 级联清成员的 builtin/catalog 资源**：catalog 自愈装的 marketplace 行重装不误清 agent 类同 slug 行——T4 三锚矩阵 + 用例
5. **类型债清零后 CI 检查面**：`tsconfig.test.json` 纳入 typecheck script 后既有 76→0 基线不回弹——T7 断言脚本
