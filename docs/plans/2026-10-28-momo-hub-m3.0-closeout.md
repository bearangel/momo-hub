# M3.0 收官清理与协议前置 — 实施计划

- **上游 spec**：`docs/specs/2026-10-28-momo-hub-m3.0-closeout.md`（已定稿，三路探查回填）
- **模式**：用户全系列预授权（过夜自主）；Momus/oracle 技术门保留
- **执行序**：hub 侧先行（tag v0.1.6 是 studio pin bump 的前置）→ studio 侧串行四票 → CI 解禁 → 收尾

## 硬约束（每票每 agent 必须遵守）

1. TypeScript strict：禁 `any`/`@ts-ignore`/`as any`；注释中文；Conventional Commits（中文正文）。
2. **测试执行串行**：同一时刻 ≤1 个 agent 跑 vitest/e2e/build；DB 重度目录加 `--pool=forks`；vitest 非正常退出后清 PPID=1 孤儿。
3. **ABI 纪律**：electron 测试前 `cd node_modules/.pnpm/better-sqlite3@*/node_modules/better-sqlite3 && npx prebuild-install`（137），跑完 `cd electron && npx electron-rebuild -f -w better-sqlite3 -w keytar` 回 149；SIGKILL 疑似 AMFI 损坏 → ad-hoc codesign 重签。renderer 测试无需切 ABI。
4. push 一律 `git -c http.version=HTTP/1.1 push`。
5. 版本 bump 仅收尾票（P6）：studio 三处 alpha.36；hub 包版本 0.1.6 在 P1 tag 时点定。
6. **T1 边界**：不加新 RPC 方法、不提 `PROTOCOL_VERSION`（仍 1.2.0）；`METHOD_REQUIRED_MINOR` 全表=2；分发守卫对 1.2 节点**逐字节零行为变化**（既有错误形状测试锁死）。
7. **T5 边界**：默认 profile 服务名与全部键**零变化**；不做跨键迁移（沿用 D2 裁决）；creds.ts 拆除自有作用域后 D2 既有测试迁移为门面层等价用例。
8. **T6 边界**：不接受 skip-if-CI 类守卫；删 testIgnore 前必须钉几何本机绿 + PR CI 全绿；CI 仍红即回滚该票单独，不裹挟其余票。
9. **T2 边界**：人话文案只经 `error-prefix.ts` 单前缀集合；`HTTP <n> <url脱敏>` 原文只进日志（redact `includeQueryToken` 沿用）。
10. 每票完成控制器复核（diff 审阅 + 测试计数 + 越界检查），不批量放行。

## 票据

### P1 · hub 仓：T1 协议前置 + T4 HOST 硬化（分支 `m3.0`，一个 deep agent）

**T1**：
- `src/version.ts`：+`minorOf(ver): number|null`、+`protocolSupports(peer, requiredMinor)`。
- `src/methods.ts`：+`METHOD_REQUIRED_MINOR: Record<string, number>`（枚举现 RPC 表全量方法=2）；`RpcErrorPayload` +可选 `method?/requiredMinor?`。
- `src/error.ts`：RpcErrorCode +'unsupported_method'。
- `packages/hub/src/server.ts`：hello 通过后 socket 状态存 peer `protoVer`（内存）；分发层（:204-213）入表方法做 minor 守卫 → `unsupported_method`（message 人类文案含双方版本）+ 载荷 `{method, requiredMinor}`；未入表维持 `unknown_method`。
- 测试：`protocol-m2.test.ts` 增 protocolSupports 矩阵；`server.integration.test.ts` 增三态（1.1 peer 调 task.list → unsupported_method 结构化；1.2/1.9 正常）+ 既有 unknown_method/4400/4402/4403 形状锁不动。
- hub 仓全量 vitest 绿。

**T4**：`packages/hub/src/index.ts`（listen 处）：`MOMO_HUB_HOST` env（默认 `127.0.0.1`），`0.0.0.0` 显式时启动日志 WARN；非法值回退默认+WARN；端口行为不变。测试三态（默认/显式/非法）。README 运行段补一句。

**收口**：hub 全量测试 → 合并回 main → 根包版本 0.1.5→0.1.6 + tag `v0.1.6` → push（含 tag）。hub CHANGELOG 条目。
