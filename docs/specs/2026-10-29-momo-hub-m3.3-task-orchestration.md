## 2. 设计

### 2.1 模型（studio electron）

- **迁移 070**：`ALTER TABLE tasks ADD COLUMN parent_task_id TEXT NULL`（引用 tasks.task_id，写路径校验存在且非终态？——校验存在即可，终态 parent 允许挂在历史下）；新表 `task_dependencies(task_id TEXT NOT NULL, depends_on_task_id TEXT NOT NULL, created_at INTEGER NOT NULL, PRIMARY KEY(task_id, depends_on_task_id))` + 两个索引（task_id / depends_on_task_id）+ `CHECK(task_id <> depends_on_task_id)`。
- **纯模块 `task/dependency-graph.ts`**：`detectCycle(existingEdges, newEdges): string[] | null`（BFS/DFS，返回环路径供报错）；`unsatisfiedDeps(taskId, statusOf): string[]`。中文注释。写路径唯一消费点。
- **blocked = 派生**：`listTasks` LEFT JOIN 聚合输出 `TaskRow.blocked: boolean` + `blockedBy: string[]`（依赖中 status NOT IN (completed) 的 T-id 列表）——**不落列、不加状态**（M3.1 waiting 先例；列镜像/9×5 锁/状态机/七态映射全部零破坏）。
- **写路径**：`createTaskFromForm` 增可选 `parentTaskId?`/`dependsOn?: string[]` → 存在性校验 + 环检测（新边并入现有图）→ 插行 + 插边（同事务）；`task:update` 增 `parentId`/`dependsOn` 进保护字段列表，新增专用通道 **`task:setDependencies`**（`{taskId, dependsOn: string[]}`——全量替换语义，替换前环检测；`{taskId, parentTaskId: string|null}` 同通道或独立 `task:setParent`——合一通道 `task:setRelations`，payload `{taskId, parentTaskId?: string|null, dependsOn?: string[]}`，字段可选各自更新）。
- **agent 路径**：`CreateTaskInput` 增 `dependsOn?: string[]`（task-tools.ts），走同一校验。
- **批量 IPC `task:createBatch`**：`{items: CreateInput[]}`（**上限 50**，超限 bad_request）→ 逐项 createTaskFromForm（含依赖校验）→ 返回 `{results: Array<{ok:true, task: TaskRow} | {ok:false, index, error}>}`（per-item union，dispatch-submit 失败聚合先例）；**部分成功允许**（与现 renderer 逐行 catch 语义一致）。
- **派发闸**：`peekNextAssigned` SQL 增 `AND NOT EXISTS (SELECT 1 FROM task_dependencies d JOIN tasks dep ON dep.task_id = d.depends_on_task_id WHERE d.task_id = t.task_id AND dep.status <> 'completed')`；`retryDispatch` 门增加 `!task.blocked`（读取派生）；`move.ts` assigned/active 目标检查追加 blocked 拒绝（人话「存在未完成依赖」）；`startTaskAndKickoff` 同拒。**blocked 任务不进入 queued/派发**（roadmap :69 逐字）。
- 依赖完成联动（可选最小面）：依赖任务终态 completed 时**不自动启动**被阻塞任务（保持拉取式——executor 轮询自然放行），仅 badge 消失。记录为设计边界。

### 2.2 渲染（studio renderer）

- `types.d.ts`：TaskRow 增 `blocked`/`blockedBy`/`parentTaskId`；`task:createBatch`/`task:setRelations` 契约。
- `task.store`：行字段透传；`createBatch` 调用替换逐行循环（CreateTaskDialog submitBatch 改单 IPC，逐项错误展示沿用现有 per-line 错误 UI）。
- **依赖输入（最小面）**：批量行语法扩展 `标题 :: T-1,T-2`（双冒号分隔依赖列表，可省略）——解析在 CreateTaskDialog（单任务模式用同输入框后缀语法，无新控件；P2 口径：无新布局语言）。spec 定稿授权。
- **DAG 视图**：TaskBoardView laneMode 增第三值 `dag`（`'flat'|'lanes'|'dag'`，LANE_MODE_STORAGE_KEY 持久化沿用）；纯模块 `renderer/src/lib/task-graph.ts`（邻接构建 + 分层拓扑 + 环回退为平铺 + 单测 colocated）；BoardCanvas 增 dag 分支：**左→右分层列**（层 = 拓扑深度，复用 BoardColumn 容器样式与 BoardCard/DelegatedTaskCard 渲染；blocked 卡角标 + blockedBy 摘要 title）；无拖拽（DAG 模式只读浏览，注释说明语义边界——状态迁移仍走看板模式）。
- **blocked 角标**：BoardCard/DelegatedTaskCard 增 Lock 图标（lucide 16px stroke 1.75，语义 token 色）+ `blockedBy` 悬停摘要；样式沿 M3.1 等待角标模式。
- 委派交互：远端委派行 blocked 同样展示（blockedBy 来自本地行派生）；dispatch 前置校验沿用 2.1 派发闸。

### 2.3 测试与验收

- electron：迁移 070 升降级；环检测矩阵（自环/两点环/三点环/跨 parent 链）；createBatch（50 上限/per-item 失败聚合/依赖校验失败只败该项）；setRelations（全量替换/环拒绝/parent 存在性）；peekNextAssigned blocked 排除；retryDispatch/move/start blocked 拒绝；listTasks blocked 派生（完成依赖消失）。DB 重度目录 `--pool=forks`。
- renderer：task-graph 拓扑分层/环回退；store batch；CreateTaskDialog `::` 语法解析；dag 模式渲染门控与只读；blocked 角标。
- 真机验收：UC-1 建依赖任务链（A→B→C）→ A 完成 前 B/C blocked 角标 + start/move 被拒（人话）；UC-2 A 完成 → B 解锁可启动；UC-3 环提交被拒（报错含环路径）；UC-4 批量创建带依赖 5 行一次 IPC（含 1 行坏依赖 → 4 成 1 败 per-line 展示）；UC-5 DAG 视图分层正确 + blocked 卡角标；UC-6 委派任务依赖本地任务 → 派发被拒直至依赖完成。
- oracle 终审 → alpha.39 + CHANGELOG → PR + CI 绿 → 合并冻结。

## 4. 风险

| 风险 | 缓解 |
|---|---|
| 环检测并发写竞态（两写交错成环） | 边写全部走同事务（INSERT 前事务内重读全图检测）；本地单进程 IPC 串行天然缓解，注释明示 |
| blocked 派生查询性能 | 边表双索引 + NOT EXISTS 半连接；limit 500 面不变 |
| 第 10 态诱惑 | 设计裁定死：blocked 非状态（M3.1 先例 + 双镜像 9×5 锁零破坏）；spec 即决议 |
| DAG 视图 P1 门禁 | 复用列/卡组件与既有 mode 切换形态，无新布局语言；验收明暗双主题截图留证 |
| 批量部分成功语义歧义 | per-item union + 现有逐行错误 UI 兼容；「与今日逐行循环语义等价」为验收口径 |
