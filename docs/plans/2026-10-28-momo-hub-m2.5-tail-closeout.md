## 契约区（实现前必须对齐）

```ts
// renderer/src/stores/resource.store.ts
/** 播种：只 replace 本次加载类型的 key（不清其他类型） */
seedHubUpdates(type: ResourceType, entries: Array<{ slug: string; version: string }>): void;
/** 已播种标记（卡片三态用）：某类型是否已成功拉取过目录 */
hubSeeded: Record<string, boolean>;
```

```ts
// electron/src/main/util/network-error.ts（新）
/** 仅用于网络层失败（fetch 抛错）；非 2xx 走既有 `下载失败: HTTP n`，不进本函数 */
export function describeNetworkError(err: unknown): string;   // 未命中分类 → '网络请求失败'
```

```ts
// electron/src/main/hub/index.ts（新导出）
/** 节点面板种子：hubGetStatus() 的本机行 + presenceSeed（后者本就剔除本机） */
export function hubGetPresenceNodes(): Array<{ nodeId: string; nodeName: string; at?: number }>;

// preload / renderer/src/ipc/types.d.ts
hub.getNodes(): Promise<Array<{ nodeId: string; nodeName: string; at?: number }>>;
```

硬约束：
1. **播种门控 = hub 源可信**：`resource:getCatalogStatus`.sources 中 `source==='hub'` 的 `degraded === false` 才播种；`degraded===true` → **完全不动**（既不清空也不新增）。`stale` 与播种无关（浏览链走 `load()`，不调 `loadFresh()`）。
2. **只 replace 本次类型**：`load()` 按 `typeFilter` 过滤（`resource.store.ts:133-138`），播种必须同类型作用域，禁止全表清空。
3. **卡片三态**：某类型未播种且无事件 → 不显示角标、**也不显示「已是最新」**；播种后按目录比较（`target > installed` 才角标，`<=` 显示「已是最新」）。M2.3 D7 锁**修订**：保留既有「无事件不复活」断言 + 新增三态断言（不删除任何既有断言）。
4. `describeNetworkError` **只覆盖 fetch 抛错**；非 2xx 维持既有 `下载失败: HTTP n`（已可读，且改动会连带 5 处断言，无收益）。未命中分类回退「网络请求失败」，禁止猜原因；原文必须 `logger.warn` 落日志。
5. 错误前缀：已知前缀常量**两侧各自存在**（electron 侧产生、renderer 侧匹配）→ 加**双侧字面量契约测试**（各自断言同一字符串集合）。真实集合：`导入失败：`/`启停失败：`/`卸载失败：`/`下载资源包失败：`（实现前用 grep 复核，缺漏补）。
6. `hub:getNodes` 只读主进程状态，**不新增 hub RPC、不改协议**；`presenceSeed` 保持剔除本机（`manager.test.ts` 已锁），本机行由 accessor 拼入。
7. renderer `pullNodes()` **只增不删**（删除仍归 `hub:nodePresence{kind:'offline'}`），防旧快照覆盖新事件。
8. `hub:nodePresence` 的 `at` **已随 `...p` 透传**（`hub/index.ts:461-464`；`types.d.ts:2653` 已声明）——本期不改事件桥，只在 `hub:getNodes` 返回里带 `at?` 保持一致。
9. hub 仓零改动；B 组决议只写 studio CHANGELOG。
