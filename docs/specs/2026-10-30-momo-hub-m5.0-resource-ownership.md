# M5.0 资源归属权威（slug 领地制 + 源头拦截）设计

- **日期**：2026-10-30
- **状态**：待评审（Momus）
- **范围**：hub 主票（db v8 + 协议 1.8.0 minor，hub v0.3.0 → v0.4.0）+ studio 从票（alpha.46）
- **上游讨论**：library-store-split（alpha.45，已交付）遗留的归属问题深讨；图文设计页 `.omo/previews/m5.0-ownership-design.html`（studio 仓，八节 + 五处变化，用户逐项裁定）
- **已裁决策链**：领地制（A）→ owner 锚 = nodeId（名字为身份入口，enroll 同名复用）→ 无主认领自救 → hello 同步改名 → unpublish owner-only（M4.4 裁关闭前提失效，重评开启）→ 发布按钮按归属隐藏 → 源头拦截免自装 + 安装链冲突拦截

## 1. 问题与目标

**问题**：hub 资源 slug 全局命名空间「先到先得但得而不占」——任何注册节点可对任何 slug 发新版（resources 行元数据含 author 被整行覆盖）、可下架任何资源；发布者本地自定义与 hub 条目无法可靠归一；发布者可自装自己发布的资源造成「自定义 + hub 版」并存。

**目标**：一个 hub 资源有唯一权威节点（owner）；归属可被 studio 感知（徽标/按钮收敛）；自装并存从源头断根。

## 2. 数据模型（hub db v8）

```sql
ALTER TABLE resources ADD COLUMN owner_node_id TEXT;  -- NULL = 无主
```

- **NULL 语义 = 开放认领**：存量迁移值（现网 hub 数据为测试性，NULL 无损——正常场景原主自己先发新版即自然认领回）
- 悬空（指向已删 nodes 行——仅手工 DB 可造成）等同开放认领
- 语义外键指向 nodes.id，不加 FK 约束（nodes 无删除面，约束冗余）

## 3. 领地规则（publish 流改造）

现有流程 `①鉴权 → ②③形态/manifest → ④版本预查 → ⑤收包 → ⑥事务 → ⑦广播 → ⑧201`，在 ③/④ 之间插 **③.5 owner 判定**：

| slug 状态 | 行为 |
|---|---|
| 新 slug | INSERT 即认领：`owner_node_id = 鉴权 nodeId`；**author 定死 = owner 名**（不再被后续发布覆盖——现状覆盖 bug 顺带消灭） |
| owner = 本节点 | 放行（元数据 upsert 保留，owner 权）；author 不变 |
| 无主（NULL/悬空） | **原子认领**：`UPDATE resources SET owner_node_id=? WHERE slug=? AND (owner_node_id IS NULL OR owner_node_id NOT IN (SELECT id FROM nodes))`；`changes=0` → 重读 owner → 403（并发双认领天然互斥，无锁） |
| owner = 他节点 | **403 `not_owner`**（错误体 `{error:'not_owner', owner_name}`）；**优先于 409 version_exists**（越权者不探知版本存在与否——信息最小化） |

## 4. unpublish 翻转 owner-only

- M4.4 裁关闭前提「无归属模型」已不成立 → 重评开启，翻转为 **owner-only**（owner 即权威，leader-only 无必要——个人 hub 单信任域）
- 404 / 幂等 / 墓碑 / revision 语义全部不变；非 owner → 403 `not_owner` 同款（携 owner_name）

## 5. hello 同步改名（治 studio `index.ts:706` 旧瑕疵）

hello 载荷加可选 `nodeName`（旧 studio 不带 → 行为不变）：

| 分支 | 行为 |
|---|---|
| 缺省 / 与 hub 记录相同 | 行为不变 |
| 不同且未被占用 | 同事务刷 `nodes.name` + `resources.author WHERE owner_node_id = 该节点`（author=owner 展示名单一语义）；presence 广播用新名 |
| 不同但已被占用 | 按现有 hello 错误模型拒绝（hello 拒绝路径）→ studio 人话「该名称已被其他节点使用」 |

## 6. 协议 1.8.0（全可选，安全降级；无新 RPC 方法，METHOD_REQUIRED_MINOR 不动）

| 变更 | 形态 | 旧端降级 |
|---|---|---|
| `HubResourceMeta.ownerNodeId?` | catalog 目录项投影归属 | 旧 hub 无字段 → studio 徽标不显示/按钮不隐藏（安全） |
| `ResourcePublishedEvent.ownerNodeId?` | 发布事件携归属（studio 目录增量合并保留该字段） | 同上 |
| hello `nodeName?` | 连接时上报当前名 | 旧 hub 忽略 → 名字滞留（无害） |
| HTTP 403 `not_owner` | publish / unpublish 越权；错误体附 `owner_name` | 旧 studio 显原始错误（M4.1 框架补人话映射） |

## 7. studio 从票（五处变化）

1. **「已发布」徽标**：catalog 条目 `ownerNodeId === 本机 config.nodeId`（同 type+slug 且本地为 custom）→ 卡片/详情显示「✓ 已发布 vN → momo-hub」；hub 不可达时 lastGood 缓存携带，徽标滞留合理
2. **403 人话**：publish/unpublish `not_owner` → 「该资源属于节点 {owner_name}，无法{发布新版/下架}」
3. **非 owner 隐藏下架钮**：catalog `ownerNodeId` 存在且 ≠ 本机 → 不渲染下架钮（现状任何节点可见可点，点了才 403）
4. **非 owner 隐藏「发布到 hub」按钮**（用户裁定 2026-10-30）：catalog 同 type+slug `ownerNodeId` 存在且 ≠ 本机 → 不渲染发布钮（覆盖 custom 四类 + marketplace 已装 skill 两类可发布面）；hub 不可达/目录无此 slug/无字段 → 按钮保留（发布尝试兜底，403 人话接住）
5. **源头拦截**（用户裁定 2026-10-30，消解「自定义 + hub 版」并存）：
   - 获取弹窗：owner=本机的行**不渲染安装/更新**，改显「✓ 你的发布 · 本地 v{local} · 已发布 v{remote}」——版本流恒为 本地→hub，永不反向安装
   - **安装链拦截**：`resource:install` hub 分支遇本地同 type+slug custom/marketplace 实体在场 → 拒装 + 人话「本地已有同名自定义资源；如需安装请先删除或改名本地版本」（同时堵 mirror 自动补装路径）
   - **存量清理小票**：启动/设置页扫描已并存的同 slug 实体，owner=本机 → 引导删除 hub 副本；owner≠本机 → 提示异物可选保留

## 8. 测试计划

**hub 矩阵**（`packages/hub/tests/`）：
- 发布：新 slug 认领（owner 写入 + author 定死）/ owner 新版放行（author 不变）/ 非 owner 新版 403（**同 version 越权者也拿 403——403 先于 409**）/ 非 owner 新 slug 不受影响
- 无主认领：NULL 认领 / 悬空认领 / **并发双认领互斥**（changes=0 → 403）
- unpublish：owner 成功（墓碑/revision/幂等不变）/ 非 owner 403 / 不存在 404
- hello 改名：同名人复用 nodeId（既有锁回归）/ 改名未占用 → nodes.name + author 同步 / 撞名 → 拒绝
- catalog/事件投影：ownerNodeId 字段在目录与 ResourcePublishedEvent 中正确携带；studio 侧 validateHubCatalog 契约更新
- 迁移：v7→v8 后存量行 owner=NULL

**studio**：
- 徽标判定（own / 非 own / 无字段降级 / lastGood 滞留）
- 403 人话映射（publish/unpublish 两处）
- 下架钮/发布钮隐藏矩阵（owner=本机/他机/无字段/hub 不可达）
- 获取弹窗 own 行免装改显状态（本地 v 与已发布 v 并示）
- 安装链 slug 冲突拦截（hub 分支 + mirror 补装路径）
- 存量清理扫描（own → 引导删除；异物 → 提示保留）
- hello 改名冲突人话

**e2e**（mock hub）：发布 → 他节点 403 → 原主新版 → 徽标 → 弹窗 own 行免装 → 安装冲突拦截 全链

## 9. 非目标

- 管理口重指 owner（无主认领覆盖 99%，手工 SQL 兜底写 hub README）
- 被抢占反向警示徽标（发布钮已按归属隐藏，静默足够）
- 组级/团队归属（资源归属恒节点级）
- 展示归并（同 slug 多实体一卡）与安装三选（用户裁定不采）
